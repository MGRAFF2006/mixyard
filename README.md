# Mixyard

Free, open-source audio routing for independent call, recording, and monitoring mixes.

## Status

This repository is the project bootstrap. Architecture and platform feasibility are being reviewed; there is no working audio router yet.

The intended desktop targets are Linux, Windows, and macOS. Each needs its own native audio integration. Application routing, device recovery, and reliable virtual microphone outputs are central goals. Support and guarantees will be documented as implementations are verified.

## Development

Implementation instructions, build commands, and focused checks will be added with the first runnable components. There are no build or test commands in this bootstrap.
